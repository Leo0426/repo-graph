# 01 商用工具采购选型与能力验证

Status: ready-for-human

- 类型：HITL（采购决策、外部协调、预算）
- 被阻塞于：无
- 覆盖：dev-plan P0，指标 T-1 / T-2 / T-3

## 要做什么

为源代码审计工具与软件成分分析工具（SCA）完成选型与采购，并用样例工程验证候选产品对 T-1/T-2/T-3 的真实覆盖。此任务需要人类做商务决策，Agent 不应领取。

## 验收标准

- [ ] 选型报告包含至少 2 个候选产品的对比（语言覆盖、漏洞库、规范库、私有化部署形态、价格）
- [ ] 采购决定有书面记录（选了什么、为什么）
- [ ] 用样例工程实测 T-1：C、C++、C#、Python、Java、JavaScript、JSP、PHP 8 种语言可检出
- [ ] 用样例工程实测 T-2：OWASP TOP 10、CWE TOP 25 至少各命中代表项
- [ ] 用样例工程实测 T-3：GB/T 34943、GB/T 34944、GB/T 34946、GB/T 39412 四项规范检测可用
- [ ] 验证记录存入本目录（如 `vendor-eval.md`），未达标项明确标注

## 验证方式

人工评审选型报告与验证记录；样例工程实测结果可复核。
