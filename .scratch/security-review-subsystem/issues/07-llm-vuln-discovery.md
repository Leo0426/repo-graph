## 要做什么

端到端交付漏洞智能发现：输入源代码工程 → 大模型解析业务逻辑 → 输出隐蔽漏洞报告。目标识别三类成因：逻辑缺陷、权限设计不当、输入验证缺失。与 06 不同，本任务消费源码而非告警，可独立推进。

## 验收标准

- [ ] 构造样例工程，三类成因各埋设至少 1 例可复现的缺陷
- [ ] 三类样例缺陷各至少检出 1 例，报告含位置、成因分类、证据链（相关代码片段与推理依据）
- [ ] 无缺陷的对照样例工程上不产生高危等级误报
- [ ] 高性能服务器部署环境下可运行；有开关可关闭该能力
- [ ] Gradle 测试通过

## 验证方式

对样例工程与对照工程各运行一次检测，人工核对报告与埋设缺陷的对应关系。
