## 要做什么

按 dev-plan 的功能需求与技术指标逐项核对验收：FR-1 多维度检查、FR-2 审查对象覆盖、FR-3 威胁检测、FR-4/FR-5 大模型能力、T-1 语言覆盖、T-2 漏洞类型、T-3 四项国标、T-4 车载效率。汇总各 issue 的验证证据，形成验收记录。

## 验收标准

- [ ] FR-1 ~ FR-5 逐项有对应证据（issue 实测记录或演示）
- [ ] T-1 ~ T-4 逐项有实测数据，区分"通过 / 未达标 / 未验证"
- [ ] 部署形态差异核对：大模型能力仅在高性能服务器环境生效，车载环境关闭
- [ ] 验收记录写入本目录，未达标项转为后续 issue

## 验证方式

人工逐项复核证据链；必要时现场演示。
