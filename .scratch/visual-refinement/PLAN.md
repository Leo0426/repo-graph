# 第二轮视觉精修

依据用户第二轮审计，在当前工作区按七个可独立审阅的步骤推进；保留已有领域语义与未提交工作。

1. 整理 header 结构，仓库仅显示名称、桌面上限 260px，页头按钮统一，服务状态点图标化。
2. 原生 select 包装为共享 select-control，mask 箭头使用 currentColor；保留原生交互。
3. 导航行承载页面操作，删除重复标题；字段说明可键盘展开，必要范围说明留在结果脚注。
4. 搜索与漏洞记录突出名称、状态和位置，区分代码字体与上下文字体，注解收成 chip。
5. 图谱查询使用 Lucide；图例映射双语；架构建议移除内部编号与方法论代号。
6. 账户菜单提供系统/亮色/暗色，持久到本地，登录页共用；验证 OS 变化、手动覆盖和异常存储。
7. Agent 阅读字号移到时间线，移除无实际步骤含义的区块编号；登录页改为居中品牌卡片。

每一步执行 design-system 与对应工作流；最终执行全部 UI 回归、截图检查及资源打包，并刷新本地 8080 服务。
