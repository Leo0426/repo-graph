## 风格决策

采用安静的编辑式工具界面：布局而非大面积装饰建立层次，保留代码产品的结构感。
品牌使用分支节点的简洁 SVG 标记；不新增营销数字、无来源图表或虚构运行状态。
共享设计 token 是配色事实源，既有工作台 CSS 保留领域布局，D3 与行内颜色同步迁移。
不新增无需求的主题切换、外部字体/CDN或改变业务 API。
