# 长列表测量

Chrome 157.0.8103.40，1440×1000，真实模板与虚构 API 数据。每组 3 次，下表为中位数。

范围为首个列表 API 响应到浏览器被观察为已渲染；包含 JSON/界面更新和观测调度，不是纯 CPU 渲染耗时或真实服务延迟。滚动使用 45 次 requestAnimationFrame 逐步移动主阅读区，统计每次样本的 P95 帧间隔。无 CPU 节流；宿主负载和自动化会影响耗时，不推算线上提升比例。
