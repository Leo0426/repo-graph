# RepoGraph Web 设计指南

设计或修改 Web 界面时，先确定用户在页面上的首要动作。Wiki、架构报告和其他长文页面以阅读为主，源码引用承担核验。列表、表单与图谱可以复用这里的控件材质，页面结构按各自的任务确定。正式页面的行为与兼容性遵循项目约定。[项目约定](../CONTEXT.md#对外入口与交互)

## 布局

文档页优先参考 A。桌面端从左到右排列章节目录、正文和源码引用。顶栏居中放一枚磨砂玻璃胶囊，容纳目录切换、上一节、下一节和页内搜索。品牌与全局动作放在胶囊两侧。底部居中放 `文稿 / 目录 / 引用` 分段控件。主体区域滚动时，顶部和底部控件保持可达。

| 方案 | 适用任务 | 结构 |
| --- | --- | --- |
| A · 编辑式 | 阅读时顺手查引用 | 左目录、中正文、右引用。正文保持最大的可读区域。 |
| B · 专注阅读 | 连续通读长文 | 目录改成顶部横排，正文居中。通过底部分段或正文引用打开引用视图。 |
| C · 源码对照 | 逐条核验正文与代码 | 加宽右侧源码区，正文与引用并排。目录按需打开，正文首屏优先给文字。 |

## 材质与排版

把玻璃材质用在需要操作的导航和控件上。正文、目录背景和代码区使用稳定的实底。亮色样稿从纸白 `#fdfdfc`、墨色 `#171e30`、正文 `#38445a`、辅助文字 `#5c6980`、侧栏 `#f5f7fb` 和分隔线 `#e0e5ef` 起步。深色主题沿用同样的明度层级，并按实际背景核对对比度。[Apple 的 Liquid Glass 设计参考](https://developer.apple.com/videos/play/wwdc2025/356/)

| 元素 | 设计规则 | A 稿参考值 |
| --- | --- | --- |
| 顶部胶囊 | 半透明的浅色材质，加细上沿高光与短阴影。相关按钮共享一个外壳。 | 全圆角，`blur(18px) saturate(1.35)`，上沿 `inset 0 1px 0 #fff`。 |
| 正文 | 用衬线标题、导语与正文建立编辑式层级。保留连续阅读的留白。短标签和操作用系统无衬线，路径、行号与代码用等宽字。 | 标题 38–67 px，导语 16–21 px，正文 16 px、行高 1.65。正文容器上限 754 px，段落上限 72ch。 |
| 底部分段 | 默认项平贴底槽。选中项微凸，接触阴影紧贴底边。 | 选中项上移 1 px，短阴影 `0 1px 2px #273f653f`。 |
| 引用按钮 | 默认透明底、低对比图标，悬停只提亮底色。当前选中项用淡蓝底、细边框和轻外发光。 | 10 px 圆角，选中边框 `#b7cef4`，外发光 `0 0 10px #8ebcff64`。 |
| 配图 | 文档内容适合配图时，用横幅承接导语和首节。画面保持低饱和，标题和正文在真实文本层排版。 | 样稿用约 3∶1 的雾蓝横幅、12 px 圆角。 |

在实际页面里通过样式变量集中管理颜色与材质。实现前可核对原型的精确参数、布局断点和状态选择器。[原型 CSS](../public/wiki-prototype.css)

## 交互状态

| 操作 | 呈现与反馈 |
| --- | --- |
| 点目录或上一节、下一节 | 跳到目标章节，键盘焦点落在标题，目录通过 `aria-current="location"` 标记当前位置。首尾处对应按钮禁用。 |
| 切换底部分段 | `文稿 / 目录 / 引用` 互斥，当前项使用 `aria-pressed`。目录内选章节后回正文定位。从引用回到文稿时恢复阅读锚点。 |
| 点正文引用或侧栏引用 | 同一组引用只有一个选中项。同步更新高亮和代码预览，显示符号名、项目内文件路径和行号。右栏收起时进入引用视图并聚焦目标。 |
| 在工作台打开源码 | 已索引引用沿用项目范围、文件和行号。索引暂无对应片段时保留原引用位置，片段不可用这一状态应可辨认。 |
| 搜索文稿 | 点击搜索或按 `⌘K` / `Ctrl+K` 打开对话框，光标进入搜索框。结果区分章节和源码引用，回车可选第一项，`Esc` 关闭，空结果有文案。 |
| 调整字号、复制链接 | `Aa` 提升正文阅读字号且保持章节可达。复制链接后反馈结果，剪贴板不可用时提示从地址栏复制。 |
| 切换仓库、文档或引用 | 当前范围与选中状态同步变更，过时响应丢弃。加载、空结果、部分完成和失败分别呈现。 |

引用选中、目录当前位置、键盘焦点是各自独立的状态。焦点用清晰的可见轮廓，引用发光跟随实际选中项。图标按钮提供可访问名称。长路径可在列表中省略，引用预览保留完整路径，长代码在预览内横向滚动。

## 窄屏与可访问性

- A 稿在约 830 px 及以下收起右栏，在约 590 px 及以下改为正文单列。目录和引用都能从底部分段打开。窄屏顶栏保留目录与搜索入口。
- 使用 `prefers-reduced-motion` 关闭平滑滚动和装饰性过渡。需要降低透明度时，把胶囊替换为有足够对比度的实色表面。
- 正式页面用中文、英文及亮暗主题检查标签、长标题、焦点、禁用和选中态。样稿提供浅色英文示例。

## 实现验收

1. 在桌面和约 390 px 的窄屏检查标题、导语和正文是否仍是视觉中心，验证页面整体没有横向溢出，目录、搜索、引用入口都可达。
2. 用鼠标和键盘分别跳章节、切分段、搜索并打开一条引用。核对选中样式、焦点位置、文件和行号，返回正文时核对阅读位置。
3. 有实际索引数据时，连续切换引用和仓库，检查旧请求是否会覆盖新内容。用长路径、无引用、源码片段不可用等场景检查状态反馈。
4. 有正式页面改动时，检查项目既有的中文、英文、亮暗主题、浏览器返回、刷新和深链行为。
