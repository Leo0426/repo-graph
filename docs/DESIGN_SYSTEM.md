# RepoGraph Design System

本文件只描述已有共享视觉入口；用户动作和恢复语义见 [Interaction Design](INTERACTION_DESIGN.md)。

共享视觉入口是 `repograph-app/src/main/resources/static/css/repograph.css`。正文使用系统字体
`--ui`（`--ff` 指向同一字体栈），基础字号 14px、行高 1.5；代码、符号和路径使用
`--fm`（JetBrains Mono / 系统等宽字体）。控件和辅助文字按共享角色设置，不统一缩成代码字体。

配色使用深色分层背景（`--bg: #0B1018`、`--bg-2`、`--bg-3`）、薄荷色强调
（`--mint: #6EE7B7`）与 `--text*` / `--border*` 层级。错误使用 `--red`，降级和待处理状态使用
`--amber`；状态同时提供文字或可访问名称，不能只靠颜色表达。跨面板调整先核对共享变量、
`.btn`、badge 和面板样式的消费点。

交互元素使用薄荷色 `:focus-visible` 轮廓；页面提供“跳至主内容”入口。
`prefers-reduced-motion: reduce` 下缩短动画和过渡、禁用平滑滚动；修改运行态视觉时保留该规则。
宽度不超过 760px 时导航变为抽屉，项目选择器保留在页头独立一行，底栏保留服务状态。
搜索控件换行，图谱与表单按窄屏堆叠，避免通过隐藏项目上下文压缩布局。
搜索筛选使用原生 `details`，手机首次进入默认收起并保留条件摘要。结果卡区分短名称、完整符号名、
路径与显式图谱入口；相似度作为辅助数据，不展示为概率。加载骨架与静态结果沿用同一背景层级。

Agent 作战台使用独立的 `--agent-text-*` 字号角色，保留标准和大字号两档。
调整正文、控件和提示时同时检查两档；窄屏需保留基线结论、建议与不确定度，不能隐藏结论来适配宽度。
Agent 运行列表按内容高度排列，桌面吸顶，避免随时间线拉成长空框；手机能力入口压为主次两行。
样式加载顺序以 `templates/fragments/head.html` 为准：共享 CSS 在前，`agent-workbench.css`、
`graph-workbench.css`、`stats-workbench.css`、`vulns-workbench.css` 在后，各自以面板限定作用域。
图谱提供缩放百分比与适应画布入口。

索引与项目工具分别使用 `index-workbench.css`、`tools-workbench.css`。索引配置、执行摘要、错误和
日志分区展示；阶段百分比必须标明范围，不绘制推测的总体完成度。项目工具优先展示项目列表与
概览、索引入口，再展示框架检测和 SBOM 下载。长路径可换行，避免挤压操作按钮。

符号页使用 `symbol-workbench.css`，查询范围、查询条件和符号详情分别组织；完整名称与路径可换行，
源码在独立区域内横向滚动。SBOM 使用 `sbom-workbench.css`，以可筛选的组件列表承载完整清单，关系图
作为辅助视图。图的显示上限与筛选后数量分别说明，不把截断的节点数表现为全部组件数。

项目概览按代码规模、组成分布和质量分析组织。分布条使用对应总量为分母，零值不绘制非零长度；
数量与占比同时可读。可操作的类型行使用原生按钮，并明确跳转后的搜索范围是全部已索引项目。
漏洞列表按严重程度、标题、处理状态与位置建立层次，说明和路径证据按需展开；
结果摘要仅统计当前筛选返回的记录，不能表现为整个项目的漏洞总数。

质量、测评与健康分别使用 `metrics-workbench.css`、`benchmark-workbench.css`、`health-workbench.css`。
质量页依次展示项目、六维静态指标、排名明细与可选模型建议。分数、数量与比率分层；缺失值显示未知，
无生产方法时不计算比率，条形使用列表最大值作为分母且零值宽度为零。循环依赖显示互相可达的包集合，
不以箭头暗示成员间存在精确的直接依赖路径。

测评页将语义与代码检索并列，突出 Hit@10、快照阈值与 MRR@10；结果语料与记录时间常驻页头。
查询明细使用原生折叠，保留完整说明、首次命中排名与首条结果。健康页突出汇总状态和最近收到结果的时间，
三项服务采用统一状态卡；说明区区分基础服务可达、单项检查失败与检查连接中断。
三个面板在窄屏按阅读顺序堆叠，长名称和路径换行，状态同时提供文本表达。

这些入口说明当前复用关系，不表示对比度、键盘焦点或所有 viewport 已通过自动验证；检查入口见
[Validation](VALIDATION.md)。
