# RepoGraph Design System

本文件描述共享视觉入口；动作、恢复和审核语义见 [Interaction Design](INTERACTION_DESIGN.md)。

## 样式与 token

`templates/fragments/head.html` 先加载 `tokens.css`、`base.css`，再加载各工作台的作用域样式。
旧 `repograph.css` 与 `studio.css` 已合并，不保留全站覆盖层。`tokens.css` 是颜色、字号、圆角、
密度与动效的事实源；共享控件、外壳、命令面板和空状态放在 `base.css`，领域布局放在对应工作台文件。
新样式消费角色变量，不添加近似色、局部字号或模板内联视觉样式。初始 `display:none` 是已有 JS 可见性状态入口。

- 背景三层：`--bg`、`--bg-2`、`--bg-3`。亮色为中性近白 `#f7f7f6`、白色、浅灰。
- 强调色：墨绿 `--mint`（兼容已有命名）、交互态 `--mint-d`；浅底使用 `--accent-soft` / `--accent-soft-hover`。
- 边框：`--border`、`--border-a`；文字：`--text`、`--text-2`、`--text-3`。
- 错误 `--red`、待处理/降级 `--amber`；信息/图谱类型可以使用 `--cyan` / `--purple`。
  语义色同时具有文字或可访问名称，不能只靠颜色。主要按钮前景使用 `--on-accent`。
- RGB token 用空格分隔，供 `rgb(var(--accent-rgb) / .12)` 使用；代码区域使用 `--code-bg`。
- 账户菜单提供系统 / 亮色 / 暗色三态。`repograph-theme.js` 在样式前恢复本地选择；系统模式通过 `matchMedia` 跟随偏好，亮/暗角色仍仅在 token 文件定义。页面、登录、弹窗、源码和 SVG 共用主题。

正文采用系统字体 `--ui`（`--ff` 同源），基础 14px、行高 1.5。代码、路径、符号和 ID 才用本地
JetBrains Mono / 系统等宽字体 `--fm`。Oxanium 已移除。共享字号角色为 11 / 12 / 13 / 14px，标题 20 / 24px；
不使用 7–10px 的辅助标签。Agent 保留独立 `--agent-text-*` 标准/大字号两档，调整时同时验证两档。

普通控件圆角 `--radius-control: 6px`，阅读面板、弹窗、通知使用 `--surface-radius: 8px`；
圆形状态点不受此限制。桌面控件 34px、手机至少 40px，主搜索桌面 38px / 手机 40px。
桌面页头 64px、侧栏 208px、主内容边距 24px；超宽屏限制普通阅读宽度，图谱保留画布。

## 外壳与信息层级

五个工作域使用本地 Lucide 线性图标和文字，选中态为浅强调底、深色文字加粗。
图标通过 `static/vendor/lucide/icons.svg` 和 `.icon` 引用，来源、版本与许可证随文件保留；不加载外部图标服务。
品牌使用 `img/repograph-mark.svg`。不使用终端底栏、全大写标签、宽字距、发光或雷达装饰。

主区将域内导航与页面操作合并为一行，重复的面板标题删除；Agent 保留不同含义的工作台标题。字段说明使用可键盘展开的 `help-note`，计数范围、图关系、阶段百分比等必要含义保留为结果脚注。
页头仓库选择器只显示名称，桌面宽度上限 260px，手机独立占一行。命令、服务和账户按钮共用 `icon-button`；状态点位于服务图标内，语言、主题、账户和三项基础服务明细在账户菜单内。
服务状态点跳转健康页，完整状态含可访问文字；不把基础连通解释为模型可用或索引完整。
宽度不超过 760px 时侧栏为抽屉，仓库选择器仍独立占一行。手机按阅读顺序堆叠，不隐藏上下文或证据。

仓库首页首屏直接提供列表、筛选、刷新和管理员索引入口。仓库行提供概览主入口及检索、发现、文档快捷操作，
执行时先同步该行仓库；当前仓库使用文字和边线标记。列表后只保留上下文说明，辅助工具默认折叠。
仓库列表只展示真实索引元数据，不放虚构风险数字或能力评分。
搜索模式使用紧凑分段控件，筛选默认折叠并展示条件摘要；结果用分隔线列表，区分短名称、完整符号、路径和图谱入口。
相似度是辅助数据，不是概率；代码模式禁用不支持的类型条件。

共享空状态由 `emptyState(titleKey, hintKey, icon)` 生成：图标、标题、提示使用固定层级。
Wiki、质量和 Agent 阅读区复用这一入口；错误、加载和真正空数据分别呈现，保留所在流程的重试/接入操作。

## 领域阅读区

索引和项目工具分别使用 `index-workbench.css` / `tools-workbench.css`。配置、阶段状态、错误和日志分区；
阶段百分比标明范围，不推测总体完成度。路径换行，索引入口只预填目录。

符号、依赖、项目概览分别使用 `symbol-workbench.css`、`sbom-workbench.css`、`stats-workbench.css`。
源码独立横向滚动；SBOM 以可筛选清单为主，图展示上限与筛选数量分别标明；概览分布按真实总量计算，零值不绘制非零条形。
漏洞使用 `vulns-workbench.css`：扫描/筛选为开放工具条，记录按严重程度、标题、状态和位置排列；证据按需展开，
筛选摘要只统计当前返回记录。图谱用 `graph-workbench.css`，保留缩放百分比和适应画布。

质量、测评、健康使用对应 `*-workbench.css`。缺失值显示未知，无生产方法不计算比率；列表条形以列表最大值为分母。
包循环显示互相可达集合，不以箭头伪造直接路径。测评突出 Hit@10、阈值、MRR@10、语料与记录时间；
健康区分基础连接、单项失败与检查连接中断，最近结果时间只来自有效完整响应。
健康页另按任务解释依赖，生成 Provider 的配置读取与基础健康检查分开。配置/启用/连接/实际生成分别表达；
检索、索引和图谱入口就地显示已观测到的依赖异常及恢复入口，保留用户主动尝试任务的能力。

Wiki 用 `wiki-workbench.css` 组织目录、正文、章节导航；版本、时间、状态、事实/模型来源和缺失信息保留在文档上下文，
表格与代码独立滚动。账户管理用 `admin-workbench.css`，按审核、组织、归属、Provider 和审计分区；
密钥不回填，未知价格/停用/连接失败均有明确文字。登录注册用 `auth-studio.css`，亮暗主题均采用居中品牌卡片，短屏允许滚动。

## 焦点、动效与验证

按钮/链接使用 2px 强调色焦点环、3px 间距；输入使用贴边 1px 单圈。提供跳至主内容入口。
短反馈采用 `--motion-fast: 130ms` / `--motion-enter: 180ms`，只过渡明确属性；整个面板不位移。
骨架只表示正在加载，不能模拟进度；不使用装饰性脉冲和扫描光。减少动态效果时关闭动画和过渡。
导航前景/背景同步切换，触摸不依赖 hover。通知隐藏时 inert，手机关闭按钮至少 40px。

`design-system.test.cjs` 检查亮/暗两主题、1440px/390px 的 14 个面板及登录注册；命令与菜单另验对比度、
焦点、键盘、首屏列表和图标真实几何。`visual-contrast.cjs` 只采样当前视口可测的 HTML 文字，排除 SVG、
渐变和禁用元素，不能代表完整 WCAG 审计。图谱、长时间线、手机和源码另做截图检查。
完整验证入口见 [Validation](VALIDATION.md) 和 [UI 测试说明](../repograph-app/src/test/ui/README.md)。


下拉框保留原生 select 的值、disabled、label 与键盘语义；静态模板和动态记录都包在 `select-control`，
装饰箭头由伪元素 `mask` + `currentColor` 绘制，`pointer-events:none`，不覆盖交互区域。
检索结果只有短名和签名使用等宽字体；完整符号和路径使用正文栈及次级文字，注解为紧凑 chip。
图谱查询按钮与图例使用本地 Lucide 和可翻译名称。架构建议展示依据、建议与引用，不展示工作流编号或内部方法论代号。
Agent 阅读字号位于时间线的阅读工具条，与准备任务的操作分离。

仓库、搜索与漏洞共用舒适/紧凑密度偏好。紧凑模式仅缩小间距，保留字号、完整位置、状态和可访问操作，
手机控件仍满足现有触摸尺寸。列表范围与分页使用共享展示组件，不引入新的领域实体或任务状态。
帮助标题应说明所属字段或内容，例如报警输入格式、索引语言范围、文件路径与行号格式；
当前范围、任务状态、错误和证据缺失不能仅存在于折叠帮助中。
