# RepoGraph Interaction Design

高影响流程以 [CONTEXT.md](../CONTEXT.md) 的 Agent 工作台、架构评审及审核队列定义为准。

- 面板导航写入 URL hash，刷新及浏览器前进/后退恢复当前面板；保留 `#stats=<projectId>`
  项目统计链接，未知面板回到搜索。移动导航展开后聚焦当前入口，Tab 在入口间循环，Escape 关闭；
  选择面板后关闭抽屉并聚焦主内容。全局项目选择器在窄屏仍可操作。
- 搜索输入、模式或过滤条件变更后使旧请求失效，迟到的首屏和分页响应不能覆盖新查询。
  清空时取消待执行的防抖并恢复示例入口；空输入不发请求。加载态使用 `aria-busy`，相同的在途查询
  不重复提交，分页一次只加载一页。首屏失败提供重试，分页失败保留已有结果并恢复加载按钮。
- 搜索数量变更从第一页刷新；结果数表示当前展示数量，分页后累计。手机筛选可收起并显示摘要；
  代码模式禁用不支持的类型筛选，切回语义模式保留选择。中文输入法组合结束后才检索，
  历史缓存损坏或不可写不阻断搜索。源码允许原生选中与复制，查看图谱使用显式按钮或卡片 Enter。
- 图谱先校验输入再显示加载状态；条件变化使旧请求失效，错误保留服务端信息并可重试。
  重新查询清除旧节点详情；节点支持键盘选择，适应画布基于当前节点边界。关联图的连线表示与目标
  的可达关系，不是完整调用链；大图使用静态布局并正确绑定边端点。
- 符号与文件位置查询使用页头的项目范围；查询条件、模式或项目变化使旧响应失效。404 表示未找到，
  服务失败单独提示并提供重试。文件行号必须为正整数，输入法组合期间的 Enter 不触发提交。
  符号详情提供签名、可展开源码与复制反馈；图谱入口沿用查询时的项目范围。
- SBOM 输入改变或对应项目被删除后，撤下旧结果和下载；生成失败可重试。组件筛选保留输入和焦点，
  列表支持键盘查看详情。图展示直接依赖，节点显示受限时明确提示，完整组件仍能通过列表查找。
- 全局项目切换同步已打开的漏洞与质量面板，以及 Agent、图谱和概览输入。清空选择撤下旧项目结果和
  操作目标；迟到响应不能将旧项目数据写入新选择。搜索继续使用已有的全项目检索契约。
- 项目概览使用明确的加载与失败状态，子分析失败单独提示，不把服务错误解释为没有风险或没有 Git。
  类型跳转会切回语义搜索并预设类型，不将代码搜索不支持的类型筛选表现为生效。
- 漏洞详情按需加载路径证据，展开和查看不改变漏洞状态；更新状态、扫描和生成报告分别保留错误反馈。
  漏洞报告使用原生模态对话框，关闭恢复焦点，打开期间不触发后台面板快捷键。
- 删除确认框默认聚焦取消按钮，背景设为 `inert`，Tab 焦点保持在对话框内；Escape 和遮罩点击均取消。
  关闭后恢复原触发点，触发点不可用时聚焦主内容。模态打开时不能触发后台面板快捷键。
- 剪贴板写入真正成功后才提示已复制；API 不可用或写入失败时显示错误提示。
  提示使用可访问的状态区域，Ctrl/Cmd+K 聚焦搜索；输入法组合输入不触发全局快捷键。
- 服务健康复用现有 HTMX 五秒轮询及 OOB badge 更新，手动检查和自动轮询共享在途去重。
  替换前验证三项服务状态完整且唯一；无效 200 与连接失败均撤下旧可用状态。
  初始显示检查中，全部正常才显示正常，单项错误显示降级。最近收到结果的时间仅在收到有效完整结果后
  更新，失败或语言切换不改变时间。状态表示基础连接检查，不确认模型已安装、推理成功或索引完整。
  服务描述不硬编码连接地址和模型名称；文字、可访问名称和提示随语言切换同步更新。
- 代码质量的静态报告和明细各自支持失败恢复；切换项目、页签和排序后使旧请求失效。
  模型评审的 SSE 与备用 POST 同样绑定发起项目，迟到响应不得覆盖新项目。模型关闭、失败、流无结果与
  完成分别反馈；公开增量默认折叠，后台健康刷新不重置展开状态和焦点。
- 测评读取最近保存的全局离线快照，独立于页头项目选择。刷新只读取结果，不启动测评。
  404 表示暂无结果；HTTP 错误与无效格式单独反馈。已有快照读取失败时保留结果并明确新鲜度未知。
  结果语料、原始记录时间、未命中筛选与展开项不受健康轮询影响；语言切换保留筛选、展开和焦点。
  命中分数仅在实际命中时显示，不能将相似度解释为正确概率。
- 索引启动返回 202 仅表示接收，409 表示同目录已有运行并恢复状态查询。轮询串行执行，目录变化后
  旧请求失效；连接失败保留已知结果并明确提示状态未知，不能等同于任务失败或已完成。
  `partial` 保留结果和错误，历史记录也显示错误。查阅日志时不强制滚回底部。
- 项目管理显示当前项目快照，刷新错误可重试；删除仍需要现有确认框。删除请求同时传入已知项目根目录，
  由既有接口清理索引历史。旧列表响应不能恢复已删除项目；索引入口只预填目录，不自动启动任务。
- 启动研判前需要项目；漏洞中心模式要求选中漏洞，外部报警模式要求有效的 Semgrep / SARIF JSON。
  运行中的按钮状态与服务端 Run 状态配合，避免重复提交。
- 列表轮询和步骤更新保持滚动位置与已展开的证据/审计详情；状态更新使用稳定 Run/Step ID。
- Agent 准备区可原生折叠，收起时显示项目与输入摘要；“准备研判”恢复草稿与高级选项，
  “查看运行”、主动选择运行及启动成功后定位时间线；后台轮询不会自动定位或收起准备区。
- 步骤展示能力、状态、结果引用、证据和缺失信息；模型建议保持辅助标识，人工审核仍基于原启发式报告。
- A/02 的 SSE 增量是模型公开结构化输出；默认折叠，用户展开后可查看。完成时局部替换结果，
  `stream-error` 保留服务端错误详情，不被通用连接错误覆盖。
- LLM 关闭和能力降级需要明确显示，不能表现为成功生成了模型结论；审核入口区分等待审核和已经完成。

前端入口在 `static/js/repograph-store.js`、`repograph-app.js`、`repograph-search.js`、
`repograph-agent.js` 与对应 Thymeleaf 模板。修改后实际检查键盘、窄屏、请求乱序、失败恢复及
启动/运行/降级/完成状态；这些约束不代替浏览器验收结果。视觉角色见 [Design System](DESIGN_SYSTEM.md)。
