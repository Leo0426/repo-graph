# 所有客户端复用同一授权服务与版本契约

现有 Web 与 REST 由应用提供，MCP 通过 HTTP 复用服务。增加 CLI、编码助手或远程入口后，需要在保持现有客户端可用的同时，让版本选择、权限和错误语义一致。

## 决策

- Web、HTTP、MCP、CLI 及外部事件经适配层调用同一领域服务。资源发现、范围解析、历史读取、异步任务状态和取消共享身份与权限校验。结果区分校验失败、无权、冲突、限流、暂不可用和部分结果，诊断可按请求关联。
- 发现接口或工具清单声明实际可用的协议版本、工具与资源范围。客户端显式选择范围。多范围输入只有对端声明支持时才提交，能力缺失时提示缺失项。现有深链和旧版调用沿用接收契约，在入口翻译后走同一读取或写入服务。
- 保留现有 stdio MCP。若需要远程 MCP，接入层验证请求来源与凭据，使用固定的结构化输入输出，复用 [资源授权](0002-resource-authorization.md)。MCP 传输会话和 [持久问答会话](0007-scoped-retrieval-and-conversations.md) 有各自的生命周期。
- CLI 及编码助手初版复用已有凭据。若部署跨设备授权，浏览器确认后签发限作用域凭据，授权码受过期、轮询次数和一次性消费限制，凭据按服务站点存储并可撤销。安装与更新能力具备真实制品时开放，升级按目标平台、版本、来源和摘要核验，失败保留可用旧版。
- 协作入口可将通知、问答和触发动作交给同一服务，操作需使用映射后的主体、明确的业务动作及独立的连接凭据。事件使用幂等回执和有限重试。对外发布、评论或投递继承业务权限与发布授权，执行服务提交可审查结果。

## 取舍

各客户端维护独立规则能快速上线首个入口，但会使撤权、范围限制和兼容行为分叉。统一服务减少后续审计面，要求适配层把授权、输入版本和结果差异表达清楚。已有入口回归通过后再扩展网络暴露面。

## 验收

用同一主体从多个入口读取同一快照，验证发生撤权后结果一致。旧客户端遇到不支持的新范围参数时得到清晰反馈，过期凭据和无效凭据被拒绝，授权码重放不能产生第二个凭据。提交成功和异步终态可分别读取。

## 设备授权

`REPOGRAPH_DEVICE_AUTH=1` 启用设备授权。CLI 显示服务的验证地址和短码。已有浏览器登录的用户输入短码，核对客户端名称后批准或拒绝。浏览器确认使用登录会话、同源校验和 CSRF 令牌。短码在十分钟内有效。轮询有最小间隔、退避和次数上限。服务按一次性事务消费授权请求，只签发一份有效期七天的 `knowledge.read` 凭据。凭据按服务地址保存，可从工作台撤销。账户凭据版本变更也会使旧设备凭据失效。[RFC 8628](https://www.rfc-editor.org/rfc/rfc8628.html)。

设备凭据能读取原账户有权查看的仓库知识和空间文档。范围内的每次读取重新校验权限。服务仍监听本机环回，跨设备连接需要各端通过现有受信隧道到达同一个服务。部署可按实际入口关闭该能力。

## Streamable HTTP MCP

`REPOGRAPH_REMOTE_MCP=1` 时开放 `/mcp` 并在发现接口声明传输能力。入口校验 Host、请求来源及 Bearer 凭据。每次请求独立核验身份，工具调用复用 REST 的版本、权限和错误契约。工具清单包括仓库列表、已发布快照、Wiki 页面和知识检索。JSON-RPC 使用无状态 JSON 响应，原有 stdio 客户端可继续调用既有操作。[MCP Streamable HTTP 传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)。

## 协作事件

`REPOGRAPH_COLLABORATION=1` 开放选配的 HTTP 事件入口。管理员为连接配置一个外部主体、一个普通账户及允许的仓库和问答会话，再接收独立连接凭据。凭据只能提交或查询该连接的事件。提交和读取回执时均按映射账户当前权限校验目标。撤销连接和更新账户凭据都会中止访问。

事件以连接和事件 ID 去重。Wiki 生成和问答提交复用各自的幂等请求。失败可在有限次数内重投，客户端可查询已受理任务的实时状态作为通知来源。协作回执记录动作、运行 ID、投递及任务状态。私有问题和回答继续保存在 Ask 会话中。

## CLI 和 stdio MCP 安装制品

客户端可从同一代码编译为带锁定生产依赖的目标平台归档。发布清单记录版本、系统、架构、来源和归档摘要，以发布方的 Ed25519 密钥签名。安装器先核验签名和清单，再检查复制到暂存目录的归档字节及启动情况。通过检查的版本整体移入已安装目录。启动器选择最高的已安装版本，失败的安装不会改变已有版本。已用 macOS arm64 的实际制品完成安装、损坏升级回退和升级后 CLI、MCP 联调。[Node.js 加密接口](https://nodejs.org/download/release/v24.22.1/docs/api/crypto.html#cryptoverifyalgorithm-data-key-signature-callback)。
