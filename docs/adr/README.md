## 实现验收

全套回归覆盖旧库、权限撤销、精确版本、并发幂等、强制重启、备份恢复及实际隔离执行。以下入口可用于复核对应场景。

| ADR | 验收场景 |
| --- | --- |
| 0001 | 从本地、归档或 Git 接入，发布精确快照，在工作台回访旧版源码、图谱及 Wiki |
| 0002 | 外部签名、组织与仓库双重校验、撤权、旧归属迁移和管理员修复 |
| 0003 | Git 来源身份、精确提交恢复与自动同步，归档原件摘要、复用和引用保留 |
| 0004 | 空间目录和回收、PDF 逐页引用、CSV 单元格修订、Wiki Word 导出及历史下载 |
| 0005 | 161 文件的增量发布、技术和业务视角、候选校验、历史回访和清理 |
| 0006 | 一次性预约和周期检查、文件与阶段检查点、租约、强制重启及真实 Docker 隔离执行 |
| 0007 | 私有范围、精确引用、流式续读、历史报告追问和在途撤权 |
| 0008 | 工作台、HTTP、CLI、两种 MCP 传输、设备授权和协作事件重放 |
| 0009 | 固定快照、多仓范围和本地工作副本，人工处置、补丁验证及真实 Semgrep 规则回归 |
| 0010 | 诊断和指标、备份恢复、旧写入兼容及基于旧库的回退演练 |
| 0011 | 试用与按量额度、独立余额门控、确认清理后的冲销、用量凭证补录 |

外部身份、协作、托管权益和远端 Git 平台契约使用隔离夹具验收。实际安装、更新与失败回退在 macOS arm64 上验证。外部凭据、运行位置和其他平台制品由部署方提供。
