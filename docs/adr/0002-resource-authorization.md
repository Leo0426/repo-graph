# 资源授权由服务端统一判定

现有实现支持本地账户审批、会话撤销，以及项目的个人或组织归属。增加团队协作后，同一主体在不同仓库或项目空间可能拥有不同权限。建议在现有项目范围校验之上集中计算资源授权。各入口复用同一判定，使网页、检索、后台任务和下载链接在撤权后得到一致结果。

## 决策

- 将账户身份、组织成员关系、资源所有者和资源授权分别记录。仓库和空间各有唯一所有者。管理员维护成员、可见性与生命周期，编辑者可写入及启动授权任务，读者可读取。所有权交接由所有者发起，在一次提交中确认新所有者、将原所有者转为资源管理员并记录审计。成员、可见性、关联与交接写入校验资源修订，发生并发冲突时要求重新读取。
- 校验使用有效账户、稳定组织身份与资源权限。组织归属可授予组内读取权限，组织范围可见须显式配置。资源上下文、客户端传入的范围以及会话声明仅作为请求输入。空间关联同时校验空间写权限与仓库来源授权，绑定具体仓库资源和允许的版本范围。管理他人的任务须同时满足空间管理权限和对应的仓库授权。关联读取、历史回放、导出、任务派发与敏感结果交付重新校验。解除关联只撤销经该空间获得的访问范围。
- 本地部署延用现有认证。团队部署可通过认证适配器验证外部会话，并按组织边界原子更新成员投影。同步中断保留上一次完整投影，无法确认当前授权的操作按权限要求失败关闭。身份变更后使旧会话或旧请求结果失效。仅在有明确产品需求时启用隔离访客或跨组织显式邀请。访客与普通账户分属不同授权上下文。
- 历史归属转换可重跑，保留有证据的资源归属、任务和历史引用。既有交接、撤权和新授权优先于兼容回填。缺少证据或存在冲突的资源进入人工核对，并记录授权、交接和修复审计。

## 适用范围与权衡

本地单机继续使用现有账户和组织归属。逐资源分配权限增加了成员治理和迁移成本，换来共享资源时可解释的读、写和管理边界。企业部署需要租户隔离时，为账户、组织、资源和后台任务绑定同一租户身份，再计算资源授权。可选的业务权益和计费决定操作是否满足用量与产品条件，资源授权仍决定主体可访问哪些数据。

## 验收边界

覆盖同名组织、成员停用、组织撤权、跨范围拒绝、所有权交接与并发修改。解除空间关联后检索和历史导出失去该空间的访问途径，仓库中心已有的独立授权仍然有效。模拟旧数据迁移重跑及目录同步部分失败，核对授权、故障恢复和审计结果。

## 外部身份适配器

可选团队部署用可信网关签发的短期 Ed25519 断言登录。断言校验签发方、受众、用途、有效期及当前浏览器挑战。每个断言只可兑换一次现有工作台会话。管理员以完整版本发布租户目录。成员关系、外部账号和组织映射在同一事务更新，成员变化及目录过期后的恢复会更新凭据版本。目录发布失败时保留上一份有效投影，超过有效期暂停对应外部会话。[JWT 安全操作](https://www.rfc-editor.org/rfc/rfc8725.html)、[Ed25519 签名标识](https://www.rfc-editor.org/rfc/rfc9864.html)。

外部账号与组织按签发方和租户分开，即使显示名称重合也使用不同的本地 ID。仓库首次归入租户后保留租户身份。空间按所有者归入同一租户，授权、交接和仓库关联须使用对应租户的对象。外部组织成员获得仓库读取权限，编辑由仓库管理员明确授权。部署管理员保有修复和审计入口。

## 旧数据归属核对

离线转换在新目标中保留能映射到项目且主体明确的原归属。缺失、冲突、主体未知或来源无法恢复时，根据项目 ID 输出待核对清单，并为管理员保存审计。须核对的项目缺省只允许部署管理员访问。管理员可以在现有项目归属入口修复。转换拒绝覆盖已有目标，后续授权与归属不会被重跑改写。
