# 检索固定证据版本，问答会话持久化调查范围

现有检索支持项目范围内的关键词、语义、代码相似和图谱扩展，并可构建带源码引用的证据包。已有 Agent 运行台账记录项目级任务和步骤。跨仓库和空间的知识问答需要补上精确版本、持续授权与恢复语义。拟让普通检索在单次请求中解析范围，持久问答在首轮固定获准范围和版本，借此保持引用可以核对并让断线后恢复同一次执行。

## 检索范围和证据

- 服务端先校验当前身份、资源及空间关联，再用稳定标识解析仓库、快照、Wiki 页面和文档版本。显式指定的版本只读取该版本，同名来源要求补充限定条件。省略版本时采用范围内最近可读的已完成快照。正在生成或失败的新快照无需阻塞已有可读版本。结果明确所用检索方式和范围覆盖，区分缺少索引、无命中、查询失败和无权访问。
- 多范围检索先验证请求中的全部来源，再限定数量与并发执行。已授权来源部分查询失败时返回成功结果与覆盖说明，全部失败时报告失败。异步查询返回前复核授权，防止在途撤权后仍交付证据。各索引按名次融合结果，统一排序、去重后再应用总条数上限。
- 证据包含稳定来源、实际版本和可定位的片段。源码引用定位文件与行段，Wiki 引用区分页面类型和生效修订，空间文档引用固定文件版本和段落、页面或单元格。相同证据经多个空间返回时合并并保留允许的空间归属，不同快照、修订或页型分别保留。跳转、下载和再次读取都重新执行授权。

## 会话和运行

- 会话记录所有者、范围与保留策略，覆盖单仓库、单空间及显式选择的多个来源。跨范围调查首轮确认实际纳入的集合和版本，并保持会话私有。显式仓库集合需全部获准。多空间问答可在调用者接受部分范围时跳过不可用空间，说明覆盖不足且不泄露被拒资源详情。发起调查时可在已有查看权限的前提下从历史页面指定其实际版本。后续追问和恢复沿用首轮范围。需要换版或调整范围时启动新调查。精确指向目录、文件或页面的上下文引用由服务端解析，通过授权后才可加入当前轮次，且不会扩张已固定的范围。
- 每轮具有独立运行和幂等标识，会话同一时间只接收一轮执行。接受请求时在同一事务中验证当前范围与会话状态，保存用户消息和运行再排队。相同标识与相同请求返回原运行，内容变化则返回冲突。时间线保存有序的消息、可公开的工具结果、引用和终态。流式连接支持按事件位置续读，断开后可查询进度或继续接收。
- 模型只能通过受控工具读取本次范围内的数据。执行、状态查询、续流和历史回看均重新授权。撤权、解除关联和资料删除立即阻止相应证据及其派生答案的再次交付。获准的历史范围不会自动扩大。会话压缩可保留关键事实与已核对引用，持久范围与正式执行状态继续以记录为准。
- 运行使用时限、工具额度和模型用量预算。取消、超时、部分完成和失败分别记录。崩溃后凭持久记录恢复或显式终结，每次尝试仅能提交自己持有有效租约的结果。答案、用量和终态按同一完成条件发布，重复回报及晚到结果不能覆盖终态。

## 取舍

每轮重选最新版的做法更接近实时索引，但会让同一段对话引用互不兼容的源码版本。只用临时流传输答案的做法启动较快，重试却可能重复提问或计费。首轮选定版本加持久运行需要版本保留与可恢复执行，换来可查证的引用、可重放的时间线和清晰的撤权语义。先复用现有索引、证据包和本地数据库，运行及其时间线可由单进程处理。

## 验收场景

- 多仓库存在同名文件和符号时，显式旧版本精确回到旧证据，默认查询在新版生成失败时仍读到最近可读版本。
- 请求超出范围上限时被拒。多范围检索中任何显式目标越权时拒绝请求，单个授权来源查询失败时可返回其余结果和缺口。同一快照来自多个空间时去重并保留可见归属。
- 追问期间发布新版仍使用首轮版本。解除空间关联或撤权后，读取、重连和历史回看都无法继续获取被撤回的证据。
- 同一轮重复提交只产生一次运行。断开流连接、重启进程、取消或超时后可查得一致状态，旧执行尝试不能写回新运行，答案引用能还原到实际读取的证据。

## 问答接口与恢复

- 工作台的问答入口可以选择仓库和空间。Wiki 可以用当前发布快照启动会话。`POST /api/v1/ask/sessions` 接收显式范围，仓库省略快照时选择最近发布版，空间文档在会话创建时锁定版本。每轮提交需要独立的 `Idempotency-Key`。
- `GET /api/v1/ask/sessions/{sessionId}/events` 支持 JSON 游标和事件流。重连可发送 `Last-Event-ID`。会话事件和引用链接均复核当前权限。服务恢复时，已接受的检索结果可继续使用。上游模型请求的结果无法确认时，该轮记录中断终态，避免自动重复提交上游请求。
- 建立会话时可选择私有 PDF、UTF-8 Markdown 或纯文本附件，也可只选择附件。每个会话最多八个附件，单份不超过 256 KiB，合计不超过 1 MiB。文本引用固定到版本和行段，原文下载保留 BOM 与换行。PDF 引用固定到版本内页码，下载返回原始字节。创建含附件的会话使用 `Idempotency-Key`。PDF 附件以 `{ name, pdfBase64 }` 提交，预览和检索使用原件文字层。
- 移除附件后，会话证据、历史答案和该文件下载暂停访问。在原会话的保留期内恢复附件，会恢复同一版本的引用与下载。要调查文件的新内容时创建新会话。
- 模型上下文最多采用十条近期终态消息，每条最多 900 字符。已提交的回答可保留最多四条已核对引用。追问无新命中且未指定新上下文时，可沿用最近一条带引用的回答，重新核验会话范围并为当前轮分配引用 ID。覆盖状态记录沿用的引用数。完整时间线仍可按游标读取。REST 的 `GET /api/v1/ask/sessions/{sessionId}/context` 与 CLI、MCP 的 `read_ask_context` 返回同一摘要和精确来源。

## 统一知识检索

空间 CSV 检索结果和问答引用携带精确修订的 `cell`。问答提交可通过上下文条目的 `cell: {row, column}` 指定单元格。搜索和引用链接重新授权后打开同一修订并定位对应单元格。

工作台的「知识检索」可选择仓库和空间。Wiki 和空间文档的「检索此版本」会锁定当前打开的修订。REST 使用 `POST /api/v1/search/knowledge`，MCP 和 CLI 使用 `search_knowledge`。请求可显式指定仓库快照、Wiki 修订、空间文档版本和空间。省略仓库快照时检索最近发布版，选择空间时检索其可读的关联仓库和当前文档版本。

单次请求最多包含八项范围，展开后最多覆盖八个仓库快照和 24 个空间文档版本。混合模式对源码使用混合检索，并按名次与 Wiki、Markdown 和 PDF 的关键词结果融合。覆盖状态区分无匹配、缺少索引和查询失败。部分结果带覆盖说明。跳转链接会重新校验相应权限和空间关联，并定位实际快照、修订与片段。空间 PDF 的检索结果和问答引用均定位冻结版本中的页码，轮次上下文可显式提供 `page`。
