# 项目概览与漏洞中心验证 — 2026-10-04（第三轮）

本轮延续现有深色薄荷主题，优化项目概览、漏洞中心及项目切换的一致性。
保留工作区此前的后端和 UI 改动；本轮没有新增后端接口或运行时依赖。

## 实现范围

- 项目概览按代码规模、组成分布、质量分析排列；数字与占比清晰分层。分布条使用对应总量为分母，
  零计数、零传出耦合和零热点分均显示零长度。可操作类型行支持键盘，明确跳转到全项目语义搜索。
- 概览提供主请求及子分析失败重试、重复加载合并、项目切换后的旧响应隔离。语言切换复用已取得的数据；
  健康轮询保持焦点和导出预览。输入改变即撤下旧项目监听及删除入口；监听操作完成后同项目刷新仍能
  收敛到实际状态。
- 漏洞中心采用紧凑筛选栏、当前结果计数、严重程度和处理状态标签、可展开的说明与路径证据。
  路径和符号在手机端换行，源码可在区域内滚动。计数只对应当前筛选，不宣称是全项目总量。
- 列表、证据、扫描、状态更新和报告保留失败反馈。查看详情不会修改漏洞状态。报告使用原生对话框，
  支持 Escape、焦点恢复、背景隔离及对话框内复制反馈；关闭后的旧响应不能重新显示内容。
- 全局项目选择同步漏洞与质量面板，Agent 内选择项目也更新页头。清空选择撤下旧结果；指标的项目、
  分类及数量变化均隔离过期响应。返回同一项目的质量面板保留已有架构建议。
- 漏洞的影响面入口使用该漏洞面板的项目和符号，避免沿用图谱旧项目；概览类型入口会从代码搜索切回
  支持类型筛选的语义搜索。搜索 API 继续使用既有的全项目契约。

视觉入口新增 `stats-workbench.css` 和 `vulns-workbench.css`，均按面板限定作用域。
设计、交互文档及 UI 测试说明同步更新。
