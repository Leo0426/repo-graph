# 索引与项目工具验证 — 2026-10-05（第四轮）

本轮沿用深色薄荷主题，将索引页按配置、执行状态、结果与日志分区，并把项目管理放到工具页首位。
保留工作区之前的后端及前三轮 UI 改动；没有新增后端 API、模型字段或运行时依赖。

## 改进

- 索引展示真实的当前阶段百分比，不推测总体进度。历史记录、部分完成、索引失败与连接中断分别说明，
  错误可展开查看；未知计数不显示为零。日志去重并保留阅读位置，最多保存 100 条。
- 索引轮询在上一次请求完成后再调度；切换目录使旧响应失效。运行中阻止重复提交，HTTP 409 恢复状态查询，
  HTTP 503 显示启动失败；连接失败提供显式重试，避免把无法确认的后台状态当作失败后重复启动。
- 配置使用原生折叠区域、标签和复选框；手机启动后收起配置并定位执行区。中英文、键盘操作及减少动画偏好
  均纳入浏览器检查。
- 项目卡片展示名称、ID、可换行根路径、索引单元和最近索引时间，支持本地筛选、概览入口和索引导航。
  加载失败保留旧列表并提示重试。索引入口只导航，不自动启动任务。
- 框架检测与 SBOM 导出提供加载、空结果、失败重试及明确下载入口。切换输入或全局项目后旧响应不能覆盖新状态，
  旧下载链接同步撤销。
- 两个删除入口均传递根目录以清理对应索引历史；删除当前项目时撤下全局选择和旧索引结果。
  删除前发出的项目列表请求不能恢复已删除项目；取消确认后恢复按钮和键盘焦点，即使期间列表刷新完成。

新增样式限定在 `index-workbench.css` 与 `tools-workbench.css`。SBOM 查看器、依赖图及 Benchmark 保持原样。
设计、交互和 UI 测试说明同步更新。
