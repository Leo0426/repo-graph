# 质量、健康与测评界面验证 — 2026-10-05（第六轮）

本轮优化代码质量、系统健康和检索效果评估三个面板，沿用现有深色薄荷主题。
保留之前的后端与五轮 UI 改动，没有新增后端接口、领域字段或运行时依赖。

## 实现范围

- 质量页按项目选择、六维静态指标、排名明细和模型建议组织。分数、数量、比率和位置分层显示，
  列表保留完整符号和路径，长内容在窄屏换行。零值条形宽度为零；缺失指标显示未知，生产方法为零时
  比率不适用。循环依赖展示互相可达的包集合，不将成员顺序画成直接依赖路径。
- 静态报告与明细各自提供错误重试，切换项目、页签或排序后使旧响应失效。模型评审的备用 POST 和 SSE
  均绑定发起项目，迟到结果不再覆盖当前项目。完成、模型关闭、失败、无结果和格式错误分别反馈；
  公开增量默认折叠，健康刷新不重置展开状态。
- 测评页保留离线快照的语料来源和原始记录时间，明确其独立于页头当前项目。语义与代码检索并列，
  摘要展示 Hit@10、快照阈值及 MRR@10。查询可按键盘展开，支持只看前十名未命中项；完整描述、排名、
  首条结果和分数按需查看，零分不丢失，相似度不解释为正确概率。
- 测评刷新只读取已保存结果。404 空态、HTTP 错误和格式错误分别处理；失败时保留已有快照并明确
  最新状态未知。旧响应不能覆盖新快照，健康刷新和语言切换保留来源、筛选、展开及焦点。
- 健康页提供汇总状态、最近收到结果的时间与手动检查。自动轮询与手动检查共享在途去重；
  替换前验证三张服务卡及三项唯一、合法的 OOB 状态。无效 HTTP 200 或连接失败会撤下旧可用状态，
  不推进收到结果的时间，恢复后自动更新。
- 服务描述移除硬编码地址和模型名称，说明基础连接检查的含义。健康页布局保持检查入口稳定，
  状态同时用颜色和文字表达，中文与英文同步。

三个面板分别使用限定作用域的 `metrics-workbench.css`、`health-workbench.css`、
`benchmark-workbench.css`；共享语言刷新挂接对应面板状态。设计、交互文档和浏览器运行说明已同步。

## 最终验证

| 检查 | 结果 | 范围 |
|---|---|---|
| 全套浏览器回归 | 129 项通过，0 失败、0 跳过 | Chrome，真实模板与静态资源，模拟 API |
| `./gradlew build -x test` | 成功 | 最终资源打包；本轮未重跑 Java 测试 |
| 修改的 JS 语法、双语键检查、`git diff --check` | 通过 | 静态检查 |
| 桌面与手机视觉核对 | 通过 | 1440 × 1000、390 × 844，含明细展开和模型建议入口 |

129 项为 Node 测试运行器计数，包含父组与子用例。本轮新增质量 10 项、测评 8 项、健康 6 项，
其余 105 项为之前回归。另修正旧健康用例的页头选择器，使“无旧绿色状态”断言检查真实 badge 容器。

专项验证先复现并修复零值条形、旧项目备用评审覆盖和测评来源被语言刷新覆盖等问题。

修复使工作区直接子区域保持自然高度；新增手机可见性检查，修后桌面约 205px、手机约 282px，
建议入口和说明完整可见。以上最终结果均在修复后运行。
