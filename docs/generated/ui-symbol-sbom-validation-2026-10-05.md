# 符号查询与 SBOM 验证 — 2026-10-05（第五轮）

本轮沿用现有深色薄荷主题，优化符号查询和 SBOM 依赖浏览。保留之前的后端及四轮 UI 改动，
没有新增后端接口、模型字段或运行时依赖。

## 实现范围

- 符号页明确查询范围、完整名称、文件路径与行号；结果按短名称、位置、所属符号、签名、注解和源码分层。
  源码可折叠、选中和复制；复制成功与失败分别反馈。完整名称和路径在手机端换行，源码只在自身区域横向滚动。
- 查询和定位使用已有接口的 `projectId` 参数，图谱跳转沿用查询时的项目范围。输入、模式或项目变化使旧响应
  失效，相同在途查询不重复提交。404、服务失败和无效响应分别处理；行号校验为后端支持的正整数。
- 中文组合输入使用显式事件监听，避免 Enter 提前提交；查询结果、未找到及失败通过简短状态区通知辅助技术。
  健康刷新和语言切换保留已展开的源码与焦点。
- SBOM 提供项目摘要、完整组件列表、持续筛选、范围过滤和组件详情。组件名称、组织、版本或 PURL 均可检索，
  搜索输入不会随结果重建而失焦。空文档与无筛选匹配分别说明；缺失版本不伪造为具体版本号。
- 关系图作为辅助视图，表示项目声明的直接依赖。修复大图连线端点，提供键盘节点选择、缩放百分比及适应画布；
  最多展示 300 个组件并明确数量，完整列表保持可检索。小图预计算布局后停止模拟，尺寸变化时重新适应画布。
- SBOM 生成支持加载、错误重试和在途去重；项目切换、清空或对应项目被删除后撤下旧结果和下载。
  非当前全局项目的删除也按实际生成目标失效，其他项目的清单不受影响。
- 桌面收紧查询、摘要和筛选区的留白，使 1440 × 1000 下组件列表起点从初版约 704px 提前至约 622px。
  手机保留至少 40px 的主要控件高度，详情优先于辅助图展示。

符号逻辑独立为 `repograph-symbol.js`，新增 `symbol-workbench.css` 与 `sbom-workbench.css`，
均按面板限定样式作用域。共享 API、项目切换和语言刷新接入对应失效及展示逻辑。
设计、交互文档与 UI 回归说明同步更新。

105 项为 Node 测试运行器计数，包含父组与子用例。本轮新增符号 9 项、SBOM 10 项、跨页面项目生命周期
4 项，其余 82 项为之前的回归。新增用例覆盖 HTTP 404/503、输入法、行号校验、旧响应、复制错误、
重复组件标识、300 节点显示上限、隐藏后恢复、尺寸变化及删除非当前项目等路径。

修复仅移除缩放容器的额外 CSS 过渡，未放宽适应画布公式；测试等待实际呈现提交，并继续要求所有节点
严格位于画布内，同时验证缩放容器没有 CSS 过渡。上述表格为修复后的完整重跑结果。
