# UI 视觉与交互验证记录 — 2026-10-04/05（六轮合并）

> 本文件是六轮 UI 验证记录的压缩合并，原文已于 2026-10-16 删除（截图与日志随验证轮次完成失去保留价值，
> 仅 `docs/screenshots/` 保留 4 张用户手册引用的归档截图）。UI 风格与交互基线见
> [Design System](../DESIGN_SYSTEM.md) 与 [Interaction Design](../INTERACTION_DESIGN.md)。

## 第一轮（2026-10-04）视觉与交互优化

统一深色薄荷配色、正文字体、等宽代码字体、控件尺寸、面板间距和焦点轮廓；≥60px 使用导航抽屉；
搜索提供示例与全项目范围提示；URL 恢复面板支持前进/后退；删除对话框隔离背景并恢复焦点；
Agent 双档字号与可折叠模型设置。验证：桌面与移动截图 + 浏览器回归。

## 第二轮（2026-10-04）核心工作流

搜索筛选区桌面展开/移动收起、分页大小切换重新查询、中文输入法组合期不发起中间查询、
历史缓存损坏不阻断检索；Agent 准备区可折叠并返回继续编辑，轮询不主动移动页面；
图谱补齐加载/空结果/失败重试，节点支持键盘选择、放大缩小与适应画布。

## 第三轮（2026-10-04）项目概览与漏洞中心

概览按代码规模、组成分布、质量分排序，分布条以对应总量为分母；语言切换复用已取数据；
监控删除入口在操作完成后同步刷新；漏洞中心采用紧凑筛选栏、当前结果计数与处理状态标签，
路径和符号在移动端换行，源码在区域内滚动。

## 第四轮（2026-10-05）索引与项目工具

索引页按配置、执行状态、结果与日志分区，展示真实阶段百分比（未知计数不显示为零）；
日志去重并保留阅读位置（最多 100 条）；索引轮询在上一次请求完成后调度，409/503/连接失败
分别给出恢复路径；项目卡片移至工具页首位，展示名称、ID、路径、索引单元与最近索引时间。

## 第五轮（2026-10-05）符号查询与 SBOM

符号页明确查询范围、完整名称与行号，源码可折叠/选中/复制并区分成功失败反馈；
查询和定位传递 `projectId`，图谱跳转沿用查询时的项目范围；SBOM 提供完整组件列表、
持久筛选、范围过滤和组件详情，缺失版本不伪造为具体版本号。

## 第六轮（2026-10-05）质量、健康与测评

质量页按项目选择、六维静态指标、排名明细和模型建议组织；循环依赖展示互相可达的包集合
（不画成直接依赖路径）；静态报告与明细各自提供错误重试，模型评审 POST 与 SSE 均绑定发起项目；
测评页保留离线快照语料来源，展示 Hit@10、快照阈值与 MRR@10，可只看前十未命中项。

## 边界

六轮均为前端资源与浏览器回归调整，无新增后端接口、领域字段或运行时依赖；
最终状态已反映在上述两份职责文档与 `docs/user-manual.md` 中，逐轮截图证据不再保留。
