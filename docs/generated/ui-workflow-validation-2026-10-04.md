# 核心工作流视觉与交互验证 — 2026-10-04（第二轮）

本轮延续深色薄荷风格，集中改善搜索、Agent 和图谱的操作路径。仅调整前端资源、浏览器回归与文档，
未新增运行时依赖或修改后端 API 契约。此前工作区中的后端改动保留。

## 已实现

- 搜索：筛选区桌面展开、手机默认收起，摘要显示当前条件；切换分页大小会重新查询，代码搜索明确禁用
  不适用的语义类型筛选。结果区突出名称、路径及显式操作，展开源码可以直接选择和复制。
- 搜索稳定性：中文输入法组合期间不发起中间查询；损坏或不可写的历史缓存不阻断检索；原生文本复制
  不再被名称复制快捷键覆盖。保留旧响应和过期分页隔离。
- Agent：准备区可折叠，通过明确入口切换到运行时间线，并可返回准备区继续编辑；切换保留草稿，
  轮询不主动移动页面。桌面运行列表更紧凑，手机能力入口改为主入口加两个次入口。
- 图谱：补齐加载、空结果、失败重试和输入提示；条件变化使旧响应失效。节点支持键盘选择，
  放大、缩小和适应画布入口持续可见，小图标签增大并移到节点下方。
- 图谱稳定性：修复大图连线坐标和旧布局定时器干扰；减少动态效果偏好生效。调用关系视图明确说明
  展示的是与目标的可达关系，避免将聚合关系误解为完整调用链。
