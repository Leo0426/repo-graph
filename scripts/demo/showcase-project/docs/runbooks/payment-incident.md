# 支付安全事件响应手册

当订单检索或退款接口出现异常参数、越权访问或数据库错误峰值时，值班人员按“证据链优先”处理。

## 告警研判与调用链

从命中的 Controller 方法开始，核对路由、参数、鉴权注解和危险调用。沿调用链确认不可信输入是否真正
到达 `executeQuery` 或 `executeUpdate`，并用安全对照路径排除仅凭关键词产生的误报。

## 影响面评估

对危险 Gateway 方法执行 Callers 与 Impact 查询，列出所有上游 API、业务服务和跨包依赖。若退款端点
缺少 `FINANCE_ADMIN` 角色证据，立即暂停公开路由并审计近期订单状态变更。

## 修复与验收

将字符串拼接替换为 `PreparedStatement`，为资金写操作增加显式角色策略。重新索引后验证风险路径消失、
安全路径仍可搜索、EXTENDS 与 IMPLEMENTS 关系不混淆，并保存扫描前后的 findings 作为审计证据。
